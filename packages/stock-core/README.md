# Stock Core

Contratos neutrales mínimos para las demos de inventario de Software Factory.

SF-004A define productos, categorías, ubicaciones, niveles, umbrales y movimientos. El paquete no contiene componentes visuales, estado, cálculos, persistencia ni reglas productivas.

Las primeras experiencias previstas son PULSE Inventory y, posteriormente, Autoparts. Los conceptos específicos de cada vertical deben permanecer fuera del Core hasta demostrar reutilización.

La definición de dominio y sus límites están documentados en [`docs/02-products/stock-core.md`](../../docs/02-products/stock-core.md).
