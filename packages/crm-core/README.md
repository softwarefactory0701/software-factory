# CRM Core

Contratos neutrales mínimos para las demos CRM de Software Factory.

CRM Core v1 define contactos, oportunidades, pipelines configurables, actividades y tareas, junto con helpers puros de consulta y agrupación validados por NOVA Realty. El paquete no contiene componentes React, hooks, estado, automatizaciones, persistencia ni conceptos inmobiliarios.

NOVA Realty será el primer consumidor y un Sales CRM general deberá validar posteriormente la reutilización. La definición completa está en [`docs/02-products/crm-core.md`](../../docs/02-products/crm-core.md).
